# Sprint 0 prototype

The first version of ProfPulse was a single HTML file: a multi-view page in plain HTML, CSS and JavaScript with real-time search, five-category ratings, a tag cloud and a review form. It had no backend, and its data lived in the page. It was used to check the user flows before any backend was written.

That file is not in this repository yet. To add it, save it in this folder as `index.html`. It opens straight from the file, with no server.
